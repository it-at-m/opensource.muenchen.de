__Proxmox VE__ is an open-source virtualization platform for running virtual machines to set up and manage x86 virtualization. 

---

The City of Munich is evaluating Proxmox as a virtualization platform and plans to run the majority of its virtual machines on Proxmox by 2027.
In order to integrate Proxmox into our lifecycle and configuration management system [Katello-Foreman](katello), we have commissioned numerous enhancements for [ForemanFogProxmox](https://github.com/theforeman/foreman_fog_proxmox/).
