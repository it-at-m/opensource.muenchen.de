**Apache ActiveMQ** ist ein freier Message Broker, der vollständig das Java Message Service implementiert.

---

Wir nutzen ActiveMQ zur Entkopplung von Software-Komponenten und zur asynchronen Kommunikation zwischen verschiedenen Fachanwendungen.
